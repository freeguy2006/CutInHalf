# 切一半 Cut In Half

只能切**一刀**，把食物切成指定的面積比例——考驗你的「目測面積」直覺！

**線上遊玩：<https://freeguy2006.github.io/CutInHalf/>**

## 遊戲說明

畫面上會出現一個去背的食物（披薩、蛋糕、西瓜、甜甜圈……）和一個目標比例（例如 `30 : 70`）。
按住滑鼠（或手指）拖曳出一條線，放開就切下去。兩塊的面積越接近目標比例，分數越高。

## 玩法

1. 按「開始」，一場遊戲共 **5 回合**，每回合滿分 1000 分（總分 5000）。
2. 每回合從 30 種食物中隨機抽一個（同一場不重複），再隨機抽一個目標比例：
   `50:50`、`40:60`、`1:2`、`30:70`、`1:3`、`20:80`。
3. 在砧板上**按住拖曳、放開即切**。你畫的線會被視為「無限延伸的直線」（整把刀劃過去），方向不限。
   - 拖曳中只有刀光，不會顯示即時百分比。
   - 拖曳距離不到 30px 視為誤觸，不算一刀。
   - 如果刀沒有碰到食物（其中一側是 0%），顯示「沒切到！」，可以重切，不扣分。
4. 切開後物品會裂成兩塊滑開，並標示實際百分比，接著顯示本回合分數與評語。
5. 5 回合結束後，結算畫面依總分給你一個稱號——「你是哪一種秤？」（共 11 級，從「用手掂一掂」到「國際公斤原器」）。

最高分會存在瀏覽器的 `localStorage`，右上角的喇叭按鈕可以靜音（狀態也會記住）。

## 計分

- 誤差 `e` = |實際較小那塊的 % − 目標較小那塊的 %|（不分左右）
- 單回合分數 = `round(1000 × (1 − e/20)^1.5)`，`e ≥ 20` 時為 0 分

| 誤差 | 0% | 1% | 2% | 5% | 10% | 20%+ |
|---|---|---|---|---|---|---|
| 分數 | 1000 | 926 | 854 | 650 | 354 | 0 |

面積用像素計算：每張圖先畫到看不見的 canvas 讀出所有像素，alpha > 128 視為物品的一部分，再用外積判斷每個像素落在刀線的哪一側，兩側像素數 ÷ 總像素數就是實際百分比。因此任何形狀都準確（包含甜甜圈中間的洞）。

完整規則（評語門檻、11 級稱號與說明、流程、視覺風格、30 個物品）請見 [規格書.md](./規格書.md)。

## 技術

- 單一 `index.html`：HTML、CSS、JavaScript、圖片（base64）全部內嵌，不依賴任何外部資源，離線也能玩。
- 原生 JavaScript、Canvas 2D、Pointer Events（滑鼠＋觸控）、Web Audio API 即時合成音效（無外部音檔）。
- 部署：GitHub Pages（`main` 分支根目錄）。

### 專案結構

```
index.html          最終成品（由建置腳本產生，請直接開啟或部署這個檔案）
規格書.md           遊戲規格
src/template.html   可編輯的原始碼樣板（圖片資料以 /*__ITEMS__*/ 佔位）
src/build.py        建置腳本：下載圖片 → 轉 base64 → 產生 index.html
src/img/            30 張 Fluent Emoji 3D PNG（建置時的快取）
LICENSE-ASSETS      圖片素材的授權聲明
```

重新建置（需要 Python 3，只用標準函式庫）：

```bash
python src/build.py
```
